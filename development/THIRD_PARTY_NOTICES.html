Third-party notices

This driver is a C++17 port of the register sequences in the Bosch Sensortec BMP5 Sensor API (bmp5.c, bmp5_defs.h, v1.1.1, github.com/boschsensortec/BMP5_SensorAPI), distributed under the BSD 3-Clause license reproduced below. Register addresses, bit masks, timing constants and the init / reset / power-mode / OSR-ODR / IIR / interrupt / NVM procedures follow that API; the FIFO and out-of-range features are not ported. No Bosch source files are included verbatim.
