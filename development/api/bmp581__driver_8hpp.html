Detailed Description

Bosch BMP581 barometric pressure sensor client (I2C or SPI via CRTP bus).

Ported from the register sequences of the Bosch BMP5 Sensor API (v1.1.1, BSD-3) into a header-only C++17 driver: chip-id / NVM-ready init, soft reset with POR check, power modes with the mandatory standby hop, OSR/ODR, IIR (standby-only write, mode restored), interrupt pin / source configuration, data-ready polling, 24-bit pressure (1/64 Pa) and temperature (1/65536 °C) read, and NVM user-word read. FIFO is intentionally out of scope.

Typical session:

bmp581::Driver<MyBus> dev(bus);
dev.Init(); // chip id + NVM ready
dev.SoftReset();
dev.Configure(bmp581::BarometricReferencePreset());
if (dev.DataReady().value) { auto s = dev.ReadSample(); }
