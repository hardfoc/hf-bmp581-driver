Detailed Description

BMP581 register map, bit fields, enumerations and timing constants.

Values follow the Bosch BMP581 data sheet (BST-BMP581-DS004) and the Bosch BMP5 Sensor API (bmp5_defs.h, v1.1.1). Register access is identical over I2C and SPI (SPI reads set bit 7 of the address).
