HF-BMP581 Driver

Header-only C++17 driver for the Bosch BMP581 barometric pressure sensor: chip-id / NVM-ready init, POR-checked soft reset, power modes with the mandatory standby hop, OSR / ODR, IIR (standby-only write with mode restore), interrupt pin and source configuration, data-ready polling, 24-bit pressure (1/64 Pa) and temperature (1/65536 °C), NVM user-word read. Register sequences ported from the Bosch BMP5 Sensor API (BSD-3).

Overview

Live documentation (GitHub Pages) — Installation, register interface, CMake, API summary, and troubleshooting.

The driver targets an absolute-pressure reference in host firmware (density compensation, gauge → absolute conversion, altitude). The BMP581 offers ±30 Pa typical absolute accuracy, 0.08 Pa RMS noise and up to 240 Hz ODR; a BarometricReferencePreset() (100 Hz, OSR ×8, IIR 3) is provided. One CRTP register transport shape serves both I2C and SPI. FIFO and out-of-range features are intentionally not ported.

Features

  • CRTP bmp581::BusInterface<Derived> — no virtual calls; you provide WriteRegs / ReadRegs / DelayUs / EnsureInitialized.
  • bmp581::Driver<BusT> — Init, SoftReset, Configure, Set/GetPowerMode, Set/GetOsrOdr, GetEffectiveOsr, Set/GetIir, ConfigureInterrupt, SelectInterruptSources, DataReady, ReadSample, ReadNvm, raw register access.
  • Typed results — DriverResult<T> with stable DriverError codes.
  • Complete register map with bit-field masks and OdrHz() helper.
  • No heap allocation; fits FreeRTOS / bare metal.
  • Host tests (-DHF_BMP581_BUILD_TESTS=ON) against a register-map fake; ESP32-S3 examples.

#include "bmp581.hpp"

MyBus bus;                                   // inherits bmp581::BusInterface<MyBus>
bmp581::Driver<MyBus> dev(bus);
dev.Init();
dev.SoftReset();
dev.Configure(bmp581::BarometricReferencePreset());
auto s = dev.ReadSample();                   // s.value.pressure_pa, s.value.temperature_c
