Detailed Description

Umbrella header for the HF-BMP581 barometric pressure sensor driver.

Pulls in bmp581::BusInterface, the register map, typed configuration / sample structs, and bmp581::Driver<BusT>. See examples/esp32/ for an ESP-IDF I2C adapter.
